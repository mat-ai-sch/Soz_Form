Das ZIP enthält die Excel-Auswertung, das Importskript und die Anleitung.
Alle drei Dateien sind mit AES-256 verschlüsselt. Das Passwort wird separat
im Chat bereitgestellt und ist nicht im Repository gespeichert.

Zum Entpacken ein Programm mit Unterstützung für AES-verschlüsselte ZIPs
verwenden, beispielsweise 7-Zip oder Keka. Bei Bedarf auf der GitHub-Dateiseite
„Download raw file“ auswählen. Die Anweisungen zur weiteren Aktualisierung
stehen im enthaltenen Dokument `Anleitung_Import.md`.
